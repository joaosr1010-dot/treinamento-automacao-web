# Treinamento de automação web com Cypress

Esse projeto tem como objetivo reforçar ainda mais o entendimento de automação web com Cypress, Page objects model (POM) e Faker.

## Tecnologias utilizadas:
- Cypress
- JavaScript
- Node.JS
- Faker
- Page Objects Model (POM)
- Cypress Cloud

 ## Conceitos aplicados:
  - Automação de testes funcionais
  - Organização dos testes/código utilizando o Page Objects Model
  - Utilização de dados aleatórios com FAKER na hora de inserir dados do cliente
  - Validação de ações
  - Integração e configuração do Cypress Cloud.

## Integração com Cypress Cloud:

- Integração do projeto com Cypress Cloud para registro e acompanhamento das execuções dos testes.
- Execução dos testes utilizando Google Chrome.
- Visualização dos resultados, histórico de execuções e Test Replay.
